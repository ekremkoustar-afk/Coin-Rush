# Coin-Rush
Practicing C++ and raylib with this project, intentionally kept simple

Goal: Collect as many coins as you can within the time limit!
Controls: WASD to move, SPACE to pause and continue

Notes:
- The HIGHSCORE-System resets every time you close the game
- The game has a fixed window size
- This Game has a lot of potential to grow, but I decided to keep it short and simple for personal practice
- Game only tested on macOS with apple silicon
- Because I don't now cmake yet I vibe-coded the txt-file
